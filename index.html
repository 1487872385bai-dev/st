PWA 安装方法（手机安装为应用） ▼

iPhone / iPad（Safari）

一、准备

  1. 电脑双击「启动局域网.bat」启动服务（--lan 模式，https 端口 3443 会自动开启）。
  2. iPhone 和电脑连接同一个 Wi-Fi。

二、信任证书（只需一次）

  1. 把 cert\ca-cert.pem 传到 iPhone（AirDrop / 微信文件传输 / 邮件均可）。
  2. iPhone 上点击该文件，提示"已下载描述文件"。
  3. 打开「设置 → 通用 → VPN 与设备管理」，点 ShorTplayer Local CA，安装（可能需输入锁屏密码）。
  4. 打开「设置 → 通用 → 关于本机 → 证书信任设置」，把 ShorTplayer Local CA 的开关打开（完全信任）。

三、Safari 安装

  1. Safari 地址栏输入：https://你的电脑IP:3443（例如 https://192.168.1.100:3443）。电脑 IP 查看方法：按 Win+R 输入 cmd，再输入 ipconfig，看 IPv4 地址。
  2. 进入应用后，点底部「分享」按钮（方框+向上箭头）。
  3. 向下滑动，选「添加到主屏幕」。
  4. 名称填 ShorTplayer，点右上角「添加」。
  5. 桌面出现图标，点开即全屏独立运行（无地址栏）。

四、注意

  • 必须用 https 地址安装，http 下 Safari 不提供全屏安装。
  • 电脑 IP 变了：运行「生成证书工具.exe」重新生成证书；只要 CA 没变，iPhone 不用重新信任，直接用新 IP 的 https 地址打开即可。
  • 只有整个 cert 文件夹丢失导致重新生成（换新 CA）时，才需要重做第二步。

Android + Chrome

一、准备工作

  1. 电脑确认 ShorTplayer 已用「启动局域网.bat」启动（--lan 模式）。
  2. 把 cert\ca-cert.pem 这个文件传到手机（微信文件传输 / QQ / 数据线 / 网盘都行）。

二、手机安装根证书（只需一次）

  1. 打开手机「设置」→「安全」→「更多安全设置 / 加密与凭据」→「安装证书」→「CA 证书」。
  2. 选择刚才传到手机的 ca-cert.pem，按提示确认安装。

三、访问并安装应用

  1. 手机连接和电脑同一个 Wi-Fi。
  2. Chrome 打开：https://你的电脑IP:3443（例如 https://192.168.1.100:3443）。电脑 IP 查看方法：按 Win+R 输入 cmd，再输入 ipconfig，看 IPv4 地址。
  3. 第一次打开若仍提示"连接不是私密连接"，点「高级」→「继续前往」即可。
  4. 进入应用后：Chrome 右上角菜单，选「安装应用」（或「添加到主屏幕」）。
  5. 手机桌面出现 ShorTplayer 图标，点开就是全屏独立应用。

四、电脑 IP 变了怎么办

不需要手动操作：双击「生成证书工具.exe」，它会自动检测电脑当前局域网 IP，发现证书没包含新 IP 时自动重新生成（复用同一个 CA，手机装过的根证书继续有效）。生成后重启 ShorTplayer 即可。手机不需要重新安装 CA 证书。

如何获取授权码？ ▼

部分功能需要授权码激活后使用。请联系 Telegram 频道 获取授权码。

应用会自动更新吗？ ▼

从 v1.0.2 起支持自动更新：

  • 电脑版：启动后自动检查，发现新版本时应用顶部会弹出「发现新版本」提示，点击「立即更新」即可自动下载、替换并重启；也可以随时刷新页面触发检查。
  • 安卓版：打开应用会静默检查，发现新版本时弹窗提示，点击「下载更新」即可获取新版安装包；也可以在「设置 → 检查更新」里手动检查。
